Ground rules

The task, the metric, and the test every idea had to pass. Everything below is judged against these.

The task and the metric (TS-AUC)

Framework
Intuition

Each series has a break-free history (1,000–5,000 points, z-scored) and then an online stretch of 10–1,000 points, read one point at a time. Half the series break somewhere in the online stretch. After every new point we output a score for "the break has already happened". At each online step the metric asks: across all series still running, do the broken ones score higher than the unbroken ones? It averages those per-step AUCs, giving most weight to steps where there are many of both kinds (steps 100–700 carry about 84% of the weight).

Math

At step \(t\), let \(P_t\) be the series with \(\tau \le t\) (positives) and \(N_t\) those without a break by \(t\), with scores \(s_{i,t}\):

$$\mathrm{AUC}_t=\frac{1}{|P_t||N_t|}\sum_{i\in P_t}\sum_{j\in N_t}\Big(\mathbb 1[s_{i,t}>s_{j,t}]+\tfrac12\mathbb 1[s_{i,t}=s_{j,t}]\Big),\qquad \text{TS-AUC}=\frac{\sum_t |P_t||N_t|\,\mathrm{AUC}_t}{\sum_t |P_t||N_t|}.$$

Training rows are weighted to match: at step \(t\) a positive row gets \(|N_t|/2\) and a negative \(|P_t|/2\), so each class's total weight at that step is \(|P_t||N_t|/2\), proportional to the metric's weight.

Decision rule used for every change: per-fold paired difference \(d_f\) against the current best, with \(\bar d \ge +0.003\), \(\bar d > 2\,\mathrm{SE}\) where \(\mathrm{SE}=\mathrm{sd}(d)/\sqrt5\), and at least 4 of 5 folds positive. For the GRU it must hold on both seeds. Late in the project, cheap blend members were also accepted at about +0.001 when consistent (5/5).

1. The base: streaming features and a tree model

Streaming feature kernel: AR whitening, running means, windows and scans

Adopted74 feats 0.594 → 270 feats 0.6155
Intuition

Breaks here are subtle: almost never a mean shift, mostly a change in variance, roughness, tails or dependence. So first remove what is predictable (an AR(10) model fitted on the history), then watch 32 simple "increment series" built from each new point and its residual: squares, absolute values, tail flags, lag products, ranks, differences at several lags. For each one, ask whether its recent average has drifted from what the history says is normal, using all online points, the last 10/30/100 points, and a scan over every possible start time. The scan matters because we don't know when the break happened; the best start time adapts to it. Simulation showed the scan beats "history vs everything so far" by 2–5 points.

Math

AR residual: \(e_t = z_t-\sum_{k=1}^{10}\hat\phi_k z_{t-k}\), with \(\hat\phi\) by least squares on the history. For each increment \(g_k(t)\) (e.g. \(e_t^2\), \(|e_t|\), \(\mathbb 1[|e_t|>3]\), \(e_te_{t-1}\), \((z_t-z_{t-\ell})^2\)) the history gives a centre \(m_k\) and a long-run variance by batch means, so autocorrelated series are not over-flagged:

$$\hat\sigma^2_{\mathrm{LR},k}=b\cdot\widehat{\mathrm{Var}}\big(\text{means of blocks of length } b\big).$$

With \(S_k(j,t)=\sum_{s=j}^{t}\big(g_k(s)-m_k\big)\):

$$Z_k^{\text{full}}(t)=\frac{S_k(1,t)}{\sqrt{t\,\hat\sigma^2_{\mathrm{LR},k}}},\qquad Z_k^{W}(t)=\frac{S_k(t-W+1,t)}{\sqrt{W\hat\sigma^2_{\mathrm{LR},k}}},\qquad \mathrm{Scan}_k(t)=\max_{j\le t-L_{\min}+1}\frac{S_k(j,t)}{\sqrt{(t-j+1)\,\hat\sigma^2_{\mathrm{LR},k}}}$$

(and the min), computed from cumulative sums in \(O(t)\) per step. Plus a decile chi-square \(\sum_b (O_b-t/10)^2/(t/10)\) on history decile bins, EWMAs and 5 history descriptors. The same compiled kernel runs in training and inference, so features are identical and causal.

Lesson: more is not better. Going from 270 to 388 features (finer tails, extra windows) hurt by −0.005: redundant features split importance and add noise.

Per-step tree classifier (LightGBM, later XGBoost on GPU)

Adopted0.6155; XGBoost same score, 2× faster
Intuition

Turn the stream into a table: one row per (series, every 3rd online step), label 1 once the break has happened. A gradient-boosted tree model learns which combinations of features mean "break", for example "tail scan high and this kind of series". Heavy regularisation (at least 2,000 rows per leaf) keeps it from memorising individual series, which each contribute about 170 near-identical rows. Logistic regression on the same features got within 0.022, so the features carry most of the signal.

Math
$$\min_F\ \sum_{i,t} w_{i,t}\,\ell\big(y_{i,t},F(\mathbf x_{i,t})\big),\qquad \ell(y,F)=-y\log\sigma(F)-(1-y)\log(1-\sigma(F)),$$

with \(F\) a sum of trees built by gradient boosting and \(w_{i,t}\) the metric-matched weights. Settings: 31 leaves, learning rate 0.03, min 2,000 rows per leaf, feature fraction 0.5; the number of rounds is picked on the cross-validated average curve.

"Predict the next point" bake-off: better models of normal

Exhaustedraw 0.5565 → AR(1) 0.575 → AR(10) 0.590; everything else flat
Intuition

If you can predict the next point better, surprises stand out more. So we tried many predictors: AR of order 1 to 50, order chosen by BIC, ridge AR, random walk, EWMA, an error scale that adapts, Student-t surprise for heavy tails, and a nonlinear GBM correction on top of AR(10). AR(10) captured all the linearly predictable structure; the nonlinear correction explained −0.05% of the remaining error (nothing). The adaptive scale was worse because it adapts the break away. (The later learned normal-behaviour model, section 6, revisited this with a different goal and did help.)

Math

Residual \(e_t=z_t-\hat z_{t\mid t-1}\) for each predictor; surprise either \(e_t^2/\hat\sigma^2\) or, for Student-t, \(-\log f_\nu(e_t/\hat\sigma)\). The adaptive scale \(\hat\sigma_t^2=\lambda\hat\sigma^2_{t-1}+(1-\lambda)e_t^2\) tracks a variance break, so \(e_t/\hat\sigma_t\) returns to normal after it: the evidence is erased.

2. A second model and how to combine

GRU sequence model fed the top-20 kernel features

Adopted0.6152 alone; 50/50 blend with trees 0.6244 (+0.0086)
Intuition

A recurrent network reads the series point by point and keeps a memory, so it can learn its own way of accumulating evidence instead of relying on fixed windows. On raw inputs it was weaker than the trees (about 0.60). Giving it the 20 most important kernel features as extra channels lifted it to the trees' level, and because it makes different mistakes, averaging the two gave +0.0086. The last 100 history points warm up its memory. Bigger networks never helped: it is short of data, not capacity.

Math
$$\mathbf h_t=\mathrm{GRU}\big(\mathbf h_{t-1},\ \mathrm{GELU}(A\mathbf x_t)\big),\qquad p_t=\sigma\big(\mathrm{MLP}(\mathbf h_t)\big),$$ $$\mathbf r_t=\sigma(W_r\mathbf u_t+U_r\mathbf h_{t-1}),\ \ \mathbf z_t=\sigma(W_z\mathbf u_t+U_z\mathbf h_{t-1}),\ \ \tilde{\mathbf h}_t=\tanh\big(W\mathbf u_t+U(\mathbf r_t\odot\mathbf h_{t-1})\big),\ \ \mathbf h_t=(1-\mathbf z_t)\odot\mathbf h_{t-1}+\mathbf z_t\odot\tilde{\mathbf h}_t.$$

Inputs \(\mathbf x_t\): \(z_t\), \(e_t\), \(e_t^2-1\), \(|e_t|-0.8\), \(e_te_{t-1}\), \(\mathbb 1[|e_t|>3]\), 6 history descriptors, an online flag, \(\log(1+t)\), and the top-20 features as \(\mathrm{clip}(\mathrm{std}(\mathrm{sign}(x)\log(1+|x|)),\pm6)\). Loss: the same weighted cross-entropy as the trees. Hidden 64, AdamW, cosine schedule, early stopping.

Blending: a fixed weighted average of logits

Adoptedplain logit average = per-step standardised (0.6244)
Intuition

The first blend standardised scores across all series at each step, which is impossible in production because series arrive one at a time. A plain weighted average of each model's logit (with one global scale per model) scored exactly the same, so that is what ships. Weight plateaus are flat, and cross-fitted ("honest") weights scored the same as in-sample ones, so the blend numbers are not overfitted.

Math
$$s_{i,t}=\sum_m w_m\,\frac{\mathrm{logit}\,p^{(m)}_{i,t}}{c_m},\qquad \sum_m w_m=1,$$

with \(c_m\) a single scale per model from training out-of-fold scores. Current weights: trees 0.5, GRU pair 0.3, SVM 0.2. AUC is rank-based, so a final sigmoid changes nothing.

Smoothing the score over time (EWMA, running max)

RejectedEWMA −0.0004 to −0.0078; running max 0.589 (much worse)
Intuition

Once a break has happened it stays happened, so maybe the score should never go down, or be smoothed. In practice the models already accumulate evidence; smoothing only adds lag, and a running max locks in early false alarms.

Math
$$\tilde s_t=\alpha s_t+(1-\alpha)\tilde s_{t-1}\quad\text{(half-life 1–8 rows)},\qquad \tilde s_t=\max\big(s_t,\ \delta\,\tilde s_{t-1}\big).$$

Stacking: a second model on top of the members

Rejected−0.0013 to −0.0044, 0–1/5 folds
Intuition

Instead of fixed weights, let a model learn how to combine the members, perhaps differently by step or series type. It lost everywhere. With history descriptors as inputs it memorised groups of series, since each series has about 170 nearly identical rows. Separate weights per step range also gained nothing. One weighted sum is already the right combiner.

Math
$$s_{i,t}=G\big(s^{(1)}_{i,t},s^{(2)}_{i,t},s^{(3)}_{i,t},\ t,\ \mathbf c_i\big),\quad G\ \text{monotone in each } s^{(m)},\ \text{cross-fitted by fold}.$$

Ranking objectives instead of classification

Rejectedtrees −0.017 on fold 0; GRU −0.0011
Intuition

The metric only cares about ordering series at the same step, so train for exactly that: penalise every (broken, unbroken) pair at the same step that is ordered wrongly. It sounds ideal but trained worse: the pairwise signal is noisier than plain per-row labels, and the trees declined after 100 rounds.

Math
$$\mathcal L=\sum_t\ \sum_{i\in P_t}\sum_{j\in N_t}\log\big(1+e^{-(s_{i,t}-s_{j,t})}\big)\quad(\text{GRU: mixed } 0.3\cdot\mathcal L_{\text{rank}}+0.7\cdot\mathcal L_{\text{BCE}}).$$

Bigger or gated GRUs, more seeds, other inputs

Rejected8 capacity settings, all within noise; 4 seeds +0.0002 in blend
Intuition

Two or three layers, hidden 96–128, learned channel gates (fixed, per series, per step), 40 instead of 20 input features, top-20 chosen from all tree features, seeds 2 and 3. None passed. The learned gates did reveal what the GRU values: time, tail scans and dependence features, not raw values. Seed averaging helps the GRU alone (+0.0024) but the blend already averages that noise away.

Math

Gate: \(\tilde{\mathbf x}_t=\mathbf g\odot\mathbf x_t\), with \(\mathbf g=\mathrm{softmax}\)-style weights averaging 1, either fixed (\(\sqrt{\text{tree importance ratio}}\)), \(\mathbf g(\mathbf c_i)\) per series, or \(\mathbf g(\mathbf c_i,\mathbf h_{t-1})\) per step.

3. More training data

Boundary re-cut augmentation

Adoptedtrees +0.0093 ± 0.0021 (5/5); GRU +0.0058 / +0.0088
Intuition

The learning curve said doubling the data is worth about +0.015. We can make new, correctly labelled series from real ones by moving the history/online boundary. Move it earlier and the end of the history becomes online data (still break-free, so the break just happens later). Move it later and the first online points (before the break) join the history. The values are real and the labels are exact. Two variants per series gave +0.009; four gave only +0.0007 more, since the variants reuse the same values.

Math

Series \((h_1..h_n \mid o_1..o_m)\), break at online index \(\tau\) (or none). Shift \(s>0\) (earlier):

$$h'=h_{1:n-s},\qquad o'=(h_{n-s+1:n},\,o_{1:m}),\qquad \tau'=\tau+s.$$

Shift \(s<0\) (later), allowed only if no break in the first \(|s|\) online points: \(h'=(h,o_{1:|s|})\), \(o'=o_{|s|+1:m}\), \(\tau'=\tau-|s|\). The new history is re-z-scored; shifts are drawn so online length and break position keep their training distributions; history stays in 1,000–5,000. Variants only train in folds where their parent trains.

History-trimming re-cuts

Rejected−0.0005 ± 0.0014 (2/5)
Intuition

Since more boundary moves stopped helping, make variants more different: also drop the start of the history, which changes every reference statistic. It gave nothing: the trees still see the same values.

Math

\(h'=h_{a+1:n}\) with the new length drawn from the history-length distribution (\(\ge1000\)); online part and labels unchanged, so labels stay exact.

Synthetic breaks injected into real data

Rejectedtrees −0.0022 / +0.0001; GRU −0.0033
Intuition

Take real break-free stretches and apply an artificial break (variance change, dependence change, heavier tails, skew, volatility clustering, splice from another series), sized so single statistics detect them about as well as real breaks. It helped after step 600 and hurt early steps. The synthetic breaks have the wrong "shape over time": some show up too early, others grow too slowly. The model learns the artificial signature, not the real one.

Math

Post-break \(x'_s=T_\theta(x_s)\) for \(s\ge\tau\), e.g. variance \(x'_s=(1+\theta)\,x_s\); dependence \(x'_s=x_s+\theta x'_{s-1}\) (rescaled). Size \(\theta\) chosen so the oracle single-statistic AUCs at \(L=30/100/300\) points after the break match the real ones (scale 0.5: 0.519/0.534/0.545 vs real 0.515/0.532/0.555).

Real labelled data from the 2025 edition

Rejected−0.0057 ± 0.0025 (1/5); source-balanced −0.0006
Intuition

The rules allow the 2025 offline-competition data: about 10,000 new real series, none shared with this edition. But it is a different population: 58% heavy-tailed (vs 15%), little autocorrelation, shorter histories, and only 29% breaks. The trees learned "series that look like 2025 rarely break", which is wrong here. Re-weighting so each source is class-balanced removed the damage but gave no gain.

Math

Source-balanced weights: per step \(t\), scale 2025 negatives by \(\rho_t=\dfrac{\sum_{\text{ext},\,y=1}w}{\sum_{\text{ext},\,y=0}w}\) so that within the source \(P(y=1)\) matches the main data's balanced prior (median factor about 0.4).

4. New evidence features

Likelihood-ratio evidence: CUSUM, Shiryaev–Roberts, Bayesian model averaging

Adoptedtrees +0.0030 ± 0.0021 (3/5); blend 0.6336 → 0.6345
Intuition

The classical sequential tests. First turn each residual into a standard normal using the series' own history (rank it against the history's residuals). Then, for 14 candidate kinds of break, ask how much more likely the recent points are under "broken" than under "normal", and keep a running tally. CUSUM restarts the tally when evidence goes negative; Shiryaev–Roberts adds up all possible start times; the Bayesian version weighs start times by how often breaks occur at each position. These are the textbook optimal detectors for a known break type.

Math

Whitening: \(w_t=\Phi^{-1}\big(\hat F_{\text{hist}}(e_t)\big)\). Likelihood ratio for alternative \(a\): \(\Lambda^{a}_s=f_a(w_s)/\varphi(w_s)\).

$$C_t=\max\big(0,\ C_{t-1}+\log\Lambda_t\big),\qquad R_t=(1+R_{t-1})\,\Lambda_t,$$ $$\frac{P(\tau\le t\mid w_{1:t})}{P(\tau>t\mid w_{1:t})}=\frac{\sum_a\omega_a\sum_{j\le t}\pi_j\prod_{s=j}^{t}\Lambda^{a}_s}{\Pi(\tau>t)},$$

with \(\pi_j\) the break-position prior (the generator's hazard) and \(\omega_a\) the weights of the 14 alternatives. Compact set: 6 features (log Bayes factor, posterior log-odds, posterior variance, ...).

Volatility state at the end of the history (frozen GARCH forecast)

Adoptedtrees +0.0070 ± 0.0013 (5/5); GRU +0.0034; blend 0.6345 → 0.6396
Intuition

The error analysis found the real obstacle: unbroken series' variance wanders on its own about as much as a typical break. But that wandering is partly predictable from the end of the history (correlation about 0.5). So instead of comparing online variance with the whole-history average, compare it with a forecast that starts at the end-of-history volatility level and decays slowly. The forecast is frozen: it never sees online data, so it cannot absorb a break. A plain GARCH decays too fast (median half-life 8 steps); the slow end-of-history level (half-life 200) is what helps. This was the largest gain since augmentation, and it showed that new information beats new algorithms.

Math

GARCH(1,1) on history residuals, fitted by grid quasi-maximum likelihood with variance targeting:

$$\sigma^2_{s+1}=\omega+\alpha e_s^2+\beta\sigma_s^2,\qquad \omega=(1-\alpha-\beta)\,\overline{e^2}.$$

Frozen path for online step \(k\), decaying to a slow end-of-history level \(L\):

$$s_f^2(k)=L+p^{\,k-1}\big(\sigma^2_{T+1}-L\big),\quad p=\alpha+\beta,\qquad L=(1-\lambda)\sum_{s\le T}\lambda^{T-s}e_s^2,\ \ \lambda=2^{-1/200}.$$

Standardised residual \(u_k=e_k/s_f(k)\); features: standardised running means and a scan of \(\min(u_k^2,25)\), \(\log\big(\overline{e^2}_{\text{online}}/\overline{s_f^2}\big)\), and 4 per-series constants (\(\log L\) at two half-lives, \(\log\sigma^2_{T+1}\), \(p\)). GRU gets \(u\), \(u^2-1\), \(\log s_f^2\).

Whole-distribution tests: KS, Anderson–Darling, Cramér–von Mises, Wasserstein

Adopted (owner)trees +0.0011 (3/5); blend +0.0017 ± 0.0008 (4/5) → 0.6413
Intuition

Instead of checking one moment at a time, compare the whole shape of the online values' distribution with the history's. Do it on the AR residual and on the volatility-adjusted residual (on raw values, autocorrelation inflates the test). Anderson–Darling, which stresses the tails, was best. The trees found it mostly redundant with their tail and variance scans, but the small blend gain was consistent, and inference cost is not scored, so it was adopted.

Math

With \(F\) the history ECDF and \(\hat F_n\) the online ECDF (evaluated on 19 history quantile edges):

$$D_{\mathrm{KS}}=\sup_x|\hat F_n-F|,\quad A^2=n\!\int\!\frac{(\hat F_n-F)^2}{F(1-F)}\,dF,\quad W^2=n\!\int(\hat F_n-F)^2dF,\quad W_1=\int|\hat F_n(x)-F(x)|\,dx.$$

Each over all online points, the last 100, and scanned over every start (segment \(\ge20\)).

Kernel SVM as a third blend member

Adopted0.6328 alone; blend +0.0012 ± 0.0004 (4/5) → 0.6427
Intuition

A smooth, non-tree model on the top 100 features. A radial kernel says "series that look alike get similar scores", which bends the decision boundary in a way trees cannot. It was much stronger than expected (nearly as good as the trees, best of all at steps 0–100), but it reads the same features as the trees (correlation about 0.83), so it adds only a little. Blending pays for different errors, not different algorithms.

Math

Random Fourier features approximate the RBF kernel \(k(\mathbf x,\mathbf x')=e^{-\gamma\|\mathbf x-\mathbf x'\|^2}\):

$$\phi(\mathbf x)=\sqrt{2/D}\,\cos(W\mathbf x+\mathbf b),\quad W_{ij}\sim\mathcal N(0,2\gamma),\ b_j\sim U[0,2\pi],\ D=8192,\ \gamma=0.5/d.$$

Least-squares SVM (weighted kernel ridge on labels \(\pm1\)), solved in closed form; one eigendecomposition gives the whole \(\lambda\) grid almost free:

$$\boldsymbol\beta(\lambda)=(\Phi^\top\Omega\Phi+\lambda I)^{-1}\Phi^\top\Omega\mathbf y=Q(\Lambda+\lambda I)^{-1}Q^\top\Phi^\top\Omega\mathbf y,\qquad \Phi^\top\Omega\Phi=Q\Lambda Q^\top.$$

Per-series calibration by replaying the history

Rejectedvariance stats +0.002–0.004 single; vol stats 0; tail stats −0.006 to −0.014
Intuition

Run each statistic on the series' own history as if it were online data, to learn how big that statistic gets for this series when nothing happens, then measure the online value against that. The volatility-state features already did this better for variance, and the replays use shorter pseudo-histories, which biases the tail and distribution statistics. With only 1–2 replays at the steps that matter, the per-series baseline was mostly noise.

Math

Pseudo-history \(h_{1:c}\), pseudo-online \(h_{c+1:c+L}\). Per-series null mean and sd at step \(k\), shrunk to the population with \(\kappa=3\):

$$\tilde m_k=\frac{n_k\bar m_k+\kappa m_k^{\text{pop}}}{n_k+\kappa},\qquad z=\frac{x-\tilde m_k}{\tilde s_k}.$$

Oracle screens: ordinal patterns, nonlinear volatility, matrix profile / FLUSS

Rejectedsingle AUCs 0.47–0.55; incremental negative or not significant
Intuition

Before building, test families with the break position known (the most favourable setting). Ordinal patterns (the up/down order of 3–4 consecutive points) are scale-free and so blind to variance changes, which is where the breaks are. Nonlinear volatility effects (leverage, clustering at longer lags, time irreversibility) showed nothing. Matrix-profile "arcs" are random in noise-like data, and raw novelty was variance in disguise. Main finding: on series whose variance did not change, nothing works. That slice looks mostly undetectable, not under-featured.

Math

Permutation entropy \(H=-\sum_{\pi}p_\pi\log p_\pi\) over the \(3!\) or \(4!\) ordinal patterns; leverage \(\mathrm{corr}(e_{t-k},e_t^2)\); irreversibility \(\mathbb E[(e_t-e_{t-1})^3]\); incremental test = cross-validated AUC of a small LightGBM, baseline vs baseline + family, paired over 3 × 5 folds.

Kernel two-sample test (MMD) on residual pairs and triples

Rejectedtrees −0.0004 ± 0.0015 (2/5)
Intuition

Compare the joint behaviour of consecutive residuals, online vs history, with a kernel test that sees any difference in distribution, including dependence. It was the only oracle family with signal (at 300 points), and mmd_u2_scan was briefly the best single feature. But it correlated 0.81–0.91 with the Anderson–Darling features: the same information again.

Math
$$\mathrm{MMD}^2(P,Q)=\|\mu_P-\mu_Q\|^2_{\mathcal H}=\mathbb E\,k(x,x')+\mathbb E\,k(y,y')-2\,\mathbb E\,k(x,y)\ \approx\ \Big\|\tfrac1n\sum_{s}\phi(\mathbf v_s)-\bar\phi_{\text{hist}}\Big\|^2,$$

with \(\mathbf v_s=(e_{s-1},e_s)\) or triples, \(\phi\) 256 random Fourier features, so each update is \(O(256)\). Normalised by the history embedding variance and segment length; full, last 100, last 300, and scan.

5. Bayesian change-point posteriors

BOCPD: exact one-break Bayesian posterior with an empirical-Bayes prior

Adoptedtrees +0.0019 ± 0.0003 (5/5, 6 SE); GRU +0.004/+0.007; blend → 0.6438
Intuition

Specialise Bayesian online change-point detection to this task: at most one break, the history is the known "before" regime, and the break position follows the generator's prior. For every possible break time, ask how well "normal before, something new after" explains the data, with the new mean and variance integrated out rather than guessed. The key was the prior on the new regime, fitted on real training breaks: typical post-break variance about 1.23× history, essentially no mean shift. That prior alone was worth +0.011 single-feature AUC over a vague one. The posterior estimates of the new variance turned out more useful to the trees than the log-odds.

Math

Pre-break \(w_s\sim\mathcal N(0,1)\); post-break \(w_s\sim\mathcal N(\mu,\sigma^2)\) with Normal–Inverse-Gamma prior \(\mu\mid\sigma^2\sim\mathcal N(0,\sigma^2/\kappa_0)\), \(\sigma^2\sim\mathrm{IG}(\alpha_0,\beta_0)\). For the segment \(w_{j:t}\) (\(n=t-j+1\), mean \(\bar w\)):

$$p(w_{j:t})=\frac{\Gamma(\alpha_n)}{\Gamma(\alpha_0)}\frac{\beta_0^{\alpha_0}}{\beta_n^{\alpha_n}}\sqrt{\frac{\kappa_0}{\kappa_n}}\,(2\pi)^{-n/2},\quad \kappa_n=\kappa_0+n,\ \alpha_n=\alpha_0+\tfrac n2,\ \beta_n=\beta_0+\tfrac12\sum_{s=j}^{t}(w_s-\bar w)^2+\frac{\kappa_0 n\bar w^2}{2\kappa_n}.$$

Bayes factor \(B_j=p(w_{j:t})\big/\prod_{s=j}^{t}\varphi(w_s)\); posterior odds of a break by \(t\):

$$O_t=\frac{\sum_{j\le t}\pi_j B_j}{\Pi(\tau>t)},\qquad q_j\propto\pi_jB_j .$$

Features: \(\log O_t\), \(\log\) BF, \(\mathbb E_q[\log(1+t-j)]\), \(\mathbb E_q[\log\sigma^2]\) (lvr), \(\mathbb E_q[\mu]\), on two streams (\(w\) and the volatility-adjusted \(w_u\)). Empirical Bayes: \(\kappa_0=490,\ \alpha_0=3.04,\ \beta_0=2.51\), so \(\mathbb E[\sigma^2]=\beta_0/(\alpha_0-1)=1.23\). \(O(t)\) per step via cumulative sums.

Richer BOCPD: autoregressive post-break model and tail-frequency stream

Rejectedtrees −0.0002 ± 0.0007 (2/5)
Intuition

Let the new regime also change its dependence (an AR(1) coefficient) and its tail frequency, and fit priors per series type. It caught a pure dependence break that the plain version missed entirely, but on real data it ranked series almost identically to the plain version (correlation 0.97), and per-type priors did not beat the global one.

Math

Post-break \(w_s=\mu+\phi w_{s-1}+\varepsilon_s\), \(\varepsilon\sim\mathcal N(0,\sigma^2)\), NIG regression prior \((\mu,\phi)\mid\sigma^2\sim\mathcal N(\mathbf m_0,\sigma^2V_0)\):

$$p(w_{j:t})=\frac{|V_n|^{1/2}}{|V_0|^{1/2}}\frac{\beta_0^{\alpha_0}\Gamma(\alpha_n)}{\beta_n^{\alpha_n}\Gamma(\alpha_0)}(2\pi)^{-n/2}.$$

Tail stream: \(b_s=\mathbb 1[|w_s|>2]\), pre-break \(p_0\approx0.0455\), post-break \(p\sim\mathrm{Beta}(a,b)\): \(B_j=\dfrac{\mathrm B(a+k,\,b+n-k)/\mathrm B(a,b)}{p_0^{k}(1-p_0)^{n-k}}\), \(k=\sum b_s\).

Shape of the break-time posterior (sharpness)

Tree run pendingsingle AUC ~0.60; linear gate ±0.0005; cv.py --pshape built, not run
Intuition

When a break really happened, the posterior over when tends to concentrate on a narrow range; with no break it stays spread out like the prior. So the shape of that posterior is evidence in itself, and it is only weakly correlated with the log-odds. A linear add-on to the blend showed nothing, but that test is known to be weak (it saw only a tenth of the NBM's real gain), so a proper tree run was built. History entropy as context was rejected outright: it is mostly history length.

Math
$$H(q)=-\sum_{j\le t}q_j\log q_j,\qquad \mathrm{KL}(q\,\|\,\tilde\pi)=\sum_j q_j\log\frac{q_j}{\tilde\pi_j},\qquad \mathrm{sd}_q\big[\log(1+t-j)\big],$$

with \(q_j=P(\tau=j\mid w_{1:t},\tau\le t)\) and \(\tilde\pi\) the prior restricted to \(j\le t\). Three per stream (bo_w, bo_wu, nb).

6. Learned normal-behaviour model

Normal-behaviour model (NBM): a pretrained GRU forecaster fed into BOCPD

Adoptedtrees +0.0049 ± 0.0014 (5/5); blend +0.0032 (5/5); SVM +0.0005; GRU +0.0007
Intuition

Train a small GRU, without any labels, to predict the next residual of break-free histories as a full Student-t distribution (location and scale). It learns each series' normal behaviour, including how volatility evolves, better than AR + GARCH. Online, measure how surprising each new point is under that forecast, rank the surprise against the series' own history, and run it through the BOCPD posterior. The result, nb_logodds, is the best single feature measured (about 0.63), and it adds signal on the slice where variance does not change, which nothing else did. Better optimisation (batch 24, 25 epochs), not width, made it work. The NBM stream also helped the SVM, which could not see this kind of information before. In the GRU it mostly duplicated what the trees already had.

Math

Inputs \(\mathbf x_t\) (11): \(z_t,\ e_t,\ \min(e_t^2,25)-1,\ \min(|e_t|,8)-0.8,\ e_te_{t-1}\), 6 history descriptors.

$$\mathbf h_t=\mathrm{GRU}(\mathbf h_{t-1},\mathrm{GELU}(A\mathbf x_t)),\qquad (m_t,\log s_t)=\mathrm{head}(\mathbf h_t),\qquad e_{t+1}\mid\mathbf h_t\sim t_\nu(m_t,s_t).$$ $$-\log p(e)=\log s+\tfrac12\log(\nu\pi)+\log\frac{\Gamma(\nu/2)}{\Gamma\big(\frac{\nu+1}{2}\big)}+\frac{\nu+1}{2}\log\Big(1+\frac{1}{\nu}\Big(\frac{e-m}{s}\Big)^2\Big).$$

Online stream: \(v_t=(e_t-m_t)/s_t\), whitened \(\tilde v_t=\Phi^{-1}(\hat F_{\text{hist}}(v_t))\) (clipped \(\pm8\)), scale drift \(d_t=\log s_t-\log s_T\). Then the BOCPD posterior on \(\tilde v\) with a per-fold empirical-Bayes prior gives \(\texttt{nb\_logodds},\ \texttt{nb\_tsb},\ \texttt{nb\_lvr},\ \texttt{nb\_mu}\), plus \(d_t\) and its mean over the last 100. In CV the NBM is pretrained per fold on that fold's training histories only.

7. Hypotheses tested and closed

Entropy rises while the break happens

Rejectedrise AUC 0.49–0.51; binned-entropy drop detector within ±0.0003
Intuition

The idea: during the switch, a rolling window holds a mix of old and new behaviour, so entropy should bump up and then settle. There was no bump at all. Breaks here are instant switches between two stationary processes, and for such subtle breaks the mixing bump (a Jensen–Shannon divergence) is tiny. Binned entropy does fall after breaks, but that is just the variance increase seen through fixed history bins, already in the models.

Math

Rolling entropy \(H_W(t)\) z-scored against the history's own rolling entropy; event-study statistic \(\mathrm{rise}=\mathrm{peak}-\max(\mathrm{pre},\mathrm{plateau})\) around \(\tau\). Note: \(\mathrm{peak}-\mathrm{plateau}\) is positive for any falling step, a trap the small runs fell into.

Backcasting: predict the past from the present

ClosedB backward stream: −0.005 to −0.011 vs forward twin; A pseudo-past: = zeros control
Intuition

(B) Run a model of normal dynamics backward: if the recent points come from a new process, backcasting the past from them should go wrong. (A) Prepend a backcast "pseudo-past" so statistics react sooner. On this data the series are time-reversible, even for a nonlinear model: the backward net predicts the past exactly as well as the forward net predicts the future, so the backward stream carries the same information, just later. The pseudo-past is a function of points already seen, so it adds nothing; its small gain matched a "prepend 30 zeros" control.

Math

Backward AR: \(e^{b}_s=z_s-\sum_{k=1}^{K}\psi_k z_{s+k}\), available only at time \(s+K\) (late by \(K+10\)). For a stationary Gaussian process \((z_1,\dots,z_n)\overset{d}{=}(z_n,\dots,z_1)\), so forward and backward residuals have the same law; only irreversibility, \(\mathbb E[e^{2}_{\text{fw}}]-\mathbb E[e^{2}_{\text{bk}}]\neq0\), could add anything, and it measured 0.52.

What the ledger says overall

New information beats new algorithms. The big steps were information the models did not have: more real data (re-cuts, +0.009), the end-of-history volatility state (+0.007), a learned forecaster's surprise (+0.005). New model types and objectives added +0.001 at most.

Members absorb each other's gains. Giving the GRU or SVM the trees' strongest new feature raises that member but barely the blend (BOCPD GRU +0.005 alone, +0.0004 in the blend). The exception is when a member could not see that kind of information at all (SVM + NBM).

Most of the remaining misses look undetectable. Series whose variance did not change sit near 0.50–0.52 for every feature family tried; about 4% of breaks change nothing on any simple axis.

Single-feature gains shrink about tenfold in the model. BOCPD: +0.011 single feature, +0.0019 trees, +0.0010 blend. Screen cheaply, but only a paired CV run decides.
